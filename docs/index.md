# Personal Assistant 101

A voice-first personal assistant I'm building for myself. Quick requests go through my iPhone's Action button; a web app holds anything longer: approving changes, reflections and voice conversations. It reads my calendar and email, keeps my to-dos, drafts messages in my voice and remembers the people in my life.

It's a personal project with one user: me. It isn't offered to anyone else.
